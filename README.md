# The Back Benchers

A modern web platform for MAKAUT students to access notes, previous year questions (PYQs), lab manuals, and exam updates. Built with Next.js and Tailwind CSS.

## Features

* Semester-wise content organization
* Notes and PYQ access
* Modern, responsive UI

## Getting Started

1.  Clone the repository:
    `git clone https://github.com/avijitdas-code/the-back-benchers.git`
2.  Navigate to the project directory:
    `cd the-back-benchers`
3.  Install dependencies:
    `npm install`
4.  Run the development server:
    `npm run dev`

Open [http://localhost:3000](http://localhost:3000) in your browser.
